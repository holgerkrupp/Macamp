# Visualization compatibility

Built-in modes are spectrum bars, oscilloscope, mirrored spectrum, radial spectrum, starfield tunnel, classic peak hold, album-art ambience, retro pattern, and GOOM. GOOM is an original native reimplementation using animated audio-reactive radial forms; it uses the shared decoded-PCM feed and the existing intensity and frame-rate controls. It does not bundle or link the LGPL GOOM engine. The renderer consumes a shared analyzed frame, independent of playback providers. The floating visualization and visualization regions in Classic and Modern skins read the same latest frame. Right-click an inline skin visualization to switch between spectrum and waveform; the existing skin-defined visualization control continues to open the floating visualizer. Classic spectrum bars use the live frame's peak hold and `VISCOLOR.TXT` spectrum/oscillator/peak colors when present.

Choose **Window → Visualization Mode → MilkDrop** for the Butterchurn renderer. **MilkDrop Presets** includes three Macamp presets and imported `.milk` files. The importer copies user-selected files into Application Support and converts numeric base values plus frame, pixel, wave, and custom-shape equations to the bundled renderer format. It bounds preset size and equation count and rejects unsafe equation tokens. External texture files and custom shader texture references are not imported. The floating window uses contiguous mono PCM from the existing analysis tap and sends at most one frame at a time to the bundled WebGL renderer. There is no Web Audio capture or second audio output. The native spectrum remains available if WebGL cannot start.

The bundled engine is Butterchurn 3.0.0-beta.5. Its unmodified module matches the upstream npm distribution and the copy in [hfyeomans/MacAmp](https://github.com/hfyeomans/MacAmp/tree/cb0c77f/Butterchurn). The WebKit script-injection approach is adapted from [ButterchurnWebView](https://github.com/hfyeomans/MacAmp/blob/cb0c77f/MacAmpApp/Views/Windows/ButterchurnWebView.swift). Both MIT notices ship with the app. The window can be resized, restored, and snapped beside the Classic player; users can browse, import, and step through supported presets.

Local file playback exposes post-EQ PCM from the local audio engine. A tap copies mono samples into a four-slot bounded single-producer/single-consumer ring; it performs no allocation, lock acquisition, or UI/stream delivery on the real-time callback. When the ring is full, the callback drops the newest frame. The consumer applies a Hann window and Accelerate/vDSP FFT, then emits log-spaced bands and a waveform at the configured UI frame rate. Paused or unsupported routes show an unavailable/silent state instead of fabricated levels.

Apple Music, hosted playback, and AVPlayer URL routes do not expose decoded PCM to Macamp. Macamp does not capture a microphone or system audio, and it does not simulate data by default. `LocalPCMAudioAnalysisSource` accepts only decoded local-engine buffers, after the equalizer node. Inline spectrum, waveform, and peak hold clear when playback pauses or the active route stops exposing PCM.

Macamp’s JSON preset is versioned and rejects unsupported versions. Windows visualization DLLs are never loaded. MilkDrop equations run only in the isolated WebKit content process after the importer's size and token checks; no native code or app message bridge is exposed to the page.
